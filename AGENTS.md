## AI agent notes (Cursor)

This repository contains a React Native + Expo app under `VoiceJournal/`.

### Where to work
- **Primary app code**: `VoiceJournal/`
- **Do not edit**: generated native folders (`VoiceJournal/android`, `VoiceJournal/ios`) unless the task explicitly requires it.

### Common commands
Run these from the repo root:

- **Install**:
  - `cd VoiceJournal && npm install`
- **Typecheck**:
  - `cd VoiceJournal && npm run typecheck`
- **Run (dev)**:
  - `cd VoiceJournal && npm run start`
- **Android debug build**:
  - `cd VoiceJournal && npm run build:android`
- **Tests**:
  - `cd VoiceJournal && npm test`
  - `cd VoiceJournal && npm run test:smoke`

### Project expectations
- Prefer TypeScript.
- Keep changes small and localized.
- Avoid adding new dependencies unless necessary; if needed, use `npm` and update `package-lock.json`.
